Google Sheets Editor Demo

Sign in with your Google account, paste a Google Sheet URL or spreadsheet ID, load a range, edit cells, and save the changes back to Google Sheets.

Before using this demo:

1. Create a project in Google Cloud Console.
2. Enable the Google Sheets API.
3. Create an OAuth 2.0 Client ID for a Web application.
4. Add your GitHub Pages origin, e.g. https://YOURNAME.github.io, to Authorized JavaScript origins.
5. Replace YOUR_GOOGLE_CLIENT_ID_HERE in this file with your real Client ID.
